title: "Manager API"
description: "Read vault data and automate manager actions over HTTP."
---

The Manager API supports vault reads, Jupiter swaps, Meteora DLMM positions and orders, Phoenix perpetuals, and vault management.

Base URL is `https://hedgin.xyz/api/external/v1`.

You need an API key with the required permissions and a manager signing key. Create a vault-scoped key under **Connect AI** in the manager console, or ask Hedgin for access your integration requires. See [Authentication](/api-reference/authentication).

The API key authorizes requests. Your signer approves transactions locally. Keep both secrets out of logs, URLs, and prompts.

<Warning>
The API operates on Solana mainnet. Sent transactions can move real funds. Start with read endpoints before enabling trading.
</Warning>

## Run an action

For raw HTTP integrations, build the action, sign the returned transaction locally, submit it with its ticket, and check status with its receipt. Follow any returned ordering or continuation fields. [Send and status](/api-reference/send-and-status) defines this contract.

An unknown result may still complete. Check its status before repeating an action.

For TypeScript, use the [SDK](/sdk/getting-started) to handle execution and outcome tracking.

## Supported operations

| Group | Coverage |
| --- | --- |
| Vault reads | Vault details, holdings, strategies, NAV, requests, history, and Phoenix accounts. |
| Market reads | Jupiter quotes, DLMM pools, and token information. |
| Trading | Jupiter swaps, DLMM liquidity and limit orders, and Phoenix setup, collateral, and orders. |
| Management | Create and update vaults, approve or reject requests, claim fees, and close strategies or vaults. |

Creating depositor requests, settling requests, editing profiles, and administrator actions are outside this API.
