---
title: "SDK overview"
description: "Automate Hedgin vaults with the TypeScript SDK."
---

`@hedginxyz/sdk` lets TypeScript bots and scripts manage Hedgin vaults. It supports Jupiter swaps, Meteora DLMM liquidity and limit orders, Phoenix perpetuals, and vault management.

Use `execute` to run an action and receive its outcome. Your manager key stays in your process. The SDK checks transactions against its signing policy before requesting a signature.

Use base-unit strings for token amounts and handle every returned outcome. If a result is unresolved, check the pending transaction before repeating the action.

For raw HTTP, use the [Manager API](/api-reference/introduction). To manage from chat, see the [Telegram bot](/managers/telegram-bot).
