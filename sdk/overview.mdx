title: "Overview"
description: "@hedginxyz/sdk is a TypeScript client for the Hedgin manager API. It runs a manager action from build to confirmation in one call and refuses to sign unsafe transactions."
---

`@hedginxyz/sdk` lets a bot or script manage a Hedgin vault: swap with Jupiter, provide liquidity on Meteora DLMM, trade Phoenix perpetuals, and administer the vault. One call runs each action from build to confirmation.

The API builds every transaction. The SDK inspects what comes back, signs it locally with your manager wallet, sends it, and tracks the result. The wallet key never leaves your process, and the SDK refuses to sign any transaction that could move funds out of the manager wallet.

<Note>
  Prefer clicking to coding? The [Telegram bot](/managers/telegram-bot) runs the same actions from a chat. For raw HTTP, see the [API reference](/api-reference/introduction).
</Note>

## How it works

<Steps>
  <Step title="Build">
    `execute` sends your action to the manager API. The API builds and simulates one or more unsigned transactions.
  </Step>
  <Step title="Inspect">
    The SDK checks every transaction against its signing policy before it signs anything. One bad transaction refuses the whole build.
  </Step>
  <Step title="Sign and send">
    Your `TransactionSigner` signs locally. The SDK sends each transaction with a short-lived ticket that proves the API built it.
  </Step>
  <Step title="Confirm">
    The SDK polls until every transaction lands or fails, follows multi-step continuations, and returns one typed `Outcome`.
  </Step>
</Steps>

## Features

<CardGroup cols={2}>
  <Card title="One call per action" icon="bolt">
    Jupiter, Meteora DLMM, Phoenix, and vault admin actions, each typed per builder.
  </Card>
  <Card title="Safe signing" icon="shield-check">
    A local policy refuses wrong payers, unknown programs, and high priority fees.
  </Card>
  <Card title="Honest outcomes" icon="circle-check">
    `confirmed`, `refused`, `failed`, or `unresolved`. It never resends a transaction with an unknown result.
  </Card>
  <Card title="Exact amounts" icon="calculator">
    Amounts are base-unit strings, never JavaScript numbers. Unit and DLMM price helpers included.
  </Card>
</CardGroup>
