Meteora DLMM lets your vault provide liquidity within a price range and earn trading fees. A range consists of **bins**, each representing a price step. Liquidity earns trading fees while its bin is active.

As the price moves, the position's token mix changes. An out-of-range position stops earning trading fees and may hold only one token.

## Open a position

1. In **Liquidity**, choose a pool. Review its token pair, price, liquidity, and fees.
2. Set the lower and upper prices.
3. Choose a liquidity shape.
4. Enter the token amounts, review the account deposit, and select **Open position**.

| Shape | Distribution |
| --- | --- |
| Spot | Evenly across the range. |
| Curve | More near the current price. |
| Bid-Ask | More at the edges. |

The console may ask for an extra setup approval when the vault first uses a pool token.

The console supports ranges up to 1,400 bins. Wide positions can complete in several steps. If a step fails, reopen the position and check what completed before continuing.

Positions and unclaimed trading fees count toward vault valuation. Unclaimed farming rewards do not.

## Manage a position

Open the position from **Liquidity** or **Portfolio**.

| Action | Result |
| --- | --- |
| Add | Add tokens to the existing range. |
| Remove | Return a chosen share of liquidity to the vault. |
| Claim fees | Move earned trading fees into the vault. |
| Flip to Bid-Ask | Redistribute selected bins holding only the non-deposit token into a Bid-Ask shape. This does not claim fees. |

If a flip fails because the pool price moved, refresh the position before trying again.

## Exit a position

Select **Zap out** to remove liquidity, claim fees, and close the position. Under **Receive in**, choose the vault's deposit token or either pool token.

If the pool does not contain the deposit token, receiving it requires an extra conversion. Review the complete exit before confirming. Choosing a non-deposit pool token keeps it in the vault.

When you receive the deposit token, a follow-up sale can also sell the vault's existing balance of the other pool token. Review that sale before confirming.

To exit manually, remove all liquidity, claim fees, then select **Close position**. Returned tokens stay in the vault. Swap them to the deposit token if you need withdrawal liquidity.

An exit can complete in several steps. If interrupted, inspect the remaining position before continuing. See [Pending or failed actions](/faq#pending-or-failed-actions).

## Place or cancel a limit order

A DLMM limit order exchanges a token when the pool reaches your selected price. Prices are quoted in token Y per token X.

1. Choose **Sell X** above the current pool price or **Buy X** below it.
2. Enter the limit price and amount.
3. Select **Place order** and approve.

To collect proceeds, fees, and any unfilled tokens, select **Cancel order** in **Portfolio**. Cancelling the whole order also closes its strategy.

## Trading restrictions

Opening positions, adding liquidity, and placing orders require Normal status. A vault in reduce-only can remove liquidity, claim fees, and cancel orders, but a protocol-wide reduce-only status blocks those actions. Paused status blocks DLMM trading and exits.
