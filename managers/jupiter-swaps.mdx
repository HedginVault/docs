Use **Swap** in the [manager console](https://hedgin.xyz/manage) to exchange vault tokens through Jupiter. The vault and protocol must allow trading.

## Make a swap

1. Choose the token to sell and the token to receive. Search by name or paste a mint address.
2. Enter the amount to sell.
3. Set **Slippage**, the maximum price movement you accept. Stay within the displayed protocol maximum.
4. Review **Price impact** and **Minimum received**, then select **Review swap** and approve.

A token's Jupiter verification mark is not a Hedgin endorsement. Check the mint address before trading an unfamiliar token.

The first purchase of a new token can require an additional setup approval and account deposit. The console tracks the token so it is included in vault valuation. You cannot swap into the vault's own share token.

## Exit a token holding

In **Portfolio**, select **Sell all & close** on the token's row. This sells the balance back to the vault's deposit token and closes its tracking record.

Close any DLMM position or limit order using the token first. If Jupiter has no route, the token remains in the vault. Try again when a route is available.

Swaps are blocked in reduce-only or paused status. For an unclear result, see [Pending or failed actions](/faq#pending-or-failed-actions).

To automate swaps, use the [SDK examples](/sdk/examples) or [Manager API](/api-reference/introduction).
